# 生成一份结构化周报

把用户给的零散记录，整理成三段式周报。

## 步骤

1. 把记录归类到三个板块：**本周完成**、**进行中**、**下周计划**。
2. 每条用「动词开头 + 结果/数据」的一句话，去掉过程流水账。
3. 完成项要能体现价值（"修复 X 导致的 Y"，而不是"改了代码"）。

## 输出模板

需要精确的排版模板时，读 `references/TEMPLATE.md`（只有需要时才读）。

## 硬规则

- 每个板块最多 5 条，抓重点。
- 有数字就上数字（覆盖率、耗时、条数）。
- 不写"继续跟进""持续优化"这类没有信息量的话。
