# 退款审批流程

按下面的步骤逐条判断，最后给出「能退/不能退」+ 依据。

## 步骤

1. **确认下单时间**：算出距今天数。
2. **核验会员等级**：不同等级的退款规则不同——需要用 search_docs 检索具体政策，别凭记忆。
3. **套用规则**：
   - 若在无理由退款时限内 → 直接可退。
   - 若超过时限，但会员等级享有豁免 → 可退。
   - 若超过时限且无豁免 → 需人工审批，不自动放行。
4. **输出结论**：一句话说清「能不能退」，并点明依据（第几步、检索到的哪条政策）。

## 硬规则

- 会员等级的退款豁免必须来自检索到的事实，不能编。
- 结论要能被审计：写清楚是哪条政策、哪一步得出的。
